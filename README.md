Internal Network Security Assessment

Project Overview

This project was completed as part of my academic Ethical Hacking coursework. It involved conducting an internal network security assessment in a controlled lab environment to identify potential vulnerabilities and evaluate security risks.

Project Objectives

Identify exposed network services.

Assess potential security weaknesses.

Understand common network vulnerabilities.

Document findings and recommend remediation measures.
